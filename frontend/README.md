# VOXELO frontend

*What you say. What AI hears.* React + TypeScript + Vite + Tailwind v4 + Recharts + Lucide.

```bash
cd frontend
npm install
npm run dev          # http://localhost:5173 (includes /api/transcribe)
npm run build        # type-check + production build
npm run preview      # serve the build, also with /api/transcribe
npm run lint
npm run data:census  # regenerate census JSON from the validated CSVs
```

## Pages

| Route | Page | Data |
| --- | --- | --- |
| `/` | Overview | speech results, transcripts, census ranking |
| `/speech` | Speech Intelligence (Q1) | `language_results.json`, `transcription_results.json` |
| `/community` | Community Intelligence (Q2) | census JSON + `speech_dataset_coverage.json` |
| `/voice` | Voice Experience | live ElevenLabs Scribe via `/api/transcribe` |

## Data

The app reads JSON from `public/data/`. Drop `language_results.json` /
`transcription_results.json` there and they replace the `*.sample.json`
placeholders automatically. Provenance flags: **S** sample placeholder,
**C** computed in the browser, **E** use with caution (Ward 10 zeros).
See [public/data/README.md](public/data/README.md).

Census JSON is generated by `scripts/convert-census.mjs` from the census team's
validated CSVs in `data/census/` (outside `public/`, never deployed; older releases
in `data/census/archive/`). The converter cross-checks the files and writes
`census_checks.json`. The `city_home_speakers` column in the coverage CSV is not used.

## Voice Experience: ElevenLabs transcription

The browser never sees the API key. Audio goes to `/api/transcribe`, a
serverless function in [`api/transcribe.ts`](api/transcribe.ts) that forwards it to
ElevenLabs Scribe (`POST /v1/speech-to-text`) and returns only the text.

- Validates type (WebM, OGG, MP3, M4A, WAV, FLAC) and size (max 4 MB, below
  Vercel's 4.5 MB request limit). Recordings are capped at 60 s in the browser.
- Audio is held in memory for the request only; nothing is stored or logged.
- Maps ElevenLabs errors to clear messages, and passes 429 rate limits through
  with `Retry-After`. A best-effort limiter allows 8 requests per minute per IP
  per server instance.
- `GET /api/transcribe` reports `{ configured }` so the page can say when no key is set.

### Local

```bash
cp .env.example .env.local     # git-ignored
# set ELEVENLABS_API_KEY=... in .env.local
npm run dev
```

A Vite plugin in `vite.config.ts` mounts the same handler for `dev` and `preview`.

### Vercel

Set the project root to `frontend/` and add `ELEVENLABS_API_KEY` (and optionally
`ELEVENLABS_STT_MODEL`, default `scribe_v1`) in Project Settings → Environment
Variables. `api/transcribe.ts` deploys as a function; `vercel.json` rewrites
other routes to the SPA.

Never prefix the key with `VITE_`. That would put it in the browser bundle.

  types/        data interfaces
